# storage

云端文件中转站 —— 打开网页拖拽上传，任何设备随时下载，**无需注册、无需令牌**。

## 在线地址

**https://polytrack114514.github.io/storage/**

## 怎么用

1. 打开上面的网址
2. 把文件拖进「上传文件」区域（也可点「选择文件」或「选择整个文件夹」）
3. 文件会直接提交到本仓库，并出现在「云端文件」列表里
4. 换任何设备打开同一网址，都能看到并下载

支持多文件、整个文件夹上传，可指定目标子目录，带进度条和逐文件状态提示。全部文件操作都通过云端中转服务完成，网页本身不保存、不接触任何 GitHub 令牌。

**在指定文件夹里继续加东西**：点开某个文件夹后，「新建文件夹」按钮会在**当前目录**下创建子文件夹；上传卡片里的「目标子目录」也会自动跟随当前浏览的目录，所以直接拖文件进来就是传到这个文件夹里（想传别处，手动改一下路径即可）。Git 仓库本身不支持空目录，新建的空文件夹用一个隐藏的 `.keep` 占位，列表里不会显示。

列表按**上传时间倒序**排列（最新上传的在最前），四个基础文件固定置顶；每个文件显示大小和上传时间。文件可按 **图片 / 文档 / 压缩包 / 其他** 分类筛选，也可按 **今天 / 最近 7 天 / 最近 30 天** 筛上传时间，并在上方搜索框里按文件名实时搜索：默认只过滤**当前目录**，按回车或点「全仓库」就跨所有文件夹搜索，结果里会显示完整路径，点「定位」可直接跳到所在目录。

**文件预览**：图片、视频（mp4/webm 等）、音频、PDF、文本类文件（txt/md/json/csv/代码等）的文件行会多出一个「预览」按钮，直接在页面弹层里查看，不用下载。文本超过 200 KB 只显示前 200 KB。

**图库视图**：点列表上方的「图库」按钮，图片会以缩略图网格展示，再点一次回到列表；选择会被记住。页面右上角的「图床」可以跳到图床站点。

每个文件右侧有这些操作：**预览**（仅可预览类型）、**复制直链**（一键把 `https://polytrack114514.github.io/storage/文件名` 复制到剪贴板）、**跳转访问**（在新标签直接打开该文件的站点地址）、**下载**、**改名**、**移动**、**删除**。文件夹行只有两个操作：**打包下载**（后端把该文件夹里所有文件打成一个 zip 返回，最大 80 MB）和**删除**。

**批量操作**：每个文件/文件夹前面有勾选框，勾选后列表上方会出现操作条——**全选当前目录**、**打包下载**（把选中的文件打成一个 zip）、**删除选中**（逐个移入回收站）、**取消选择**。

**改名 / 移动**：行内「改名」只改名称（不含路径），「移动」输入目标文件夹（留空为根目录），文件名保持不变。目标已存在时会拒绝（`409`）。文件夹也能整体改名或移动。

**上传和删除需要口令**：在「上传文件」卡片右上角的口令框里输入，浏览器会记住；口令由后端校验，不填或填错一律拒绝（`403`），绕过网页直接调接口同样无效。浏览和下载不需要口令。

**同名文件不能覆盖**：目标位置已存在同名文件时，后端直接拒绝（`409`），需要先删除旧文件再上传。

**删除是软删除**：文件不会真正消失，而是被挪到仓库的 `.trash` 目录，页面右上角「回收站」里可以看到它，并选择**恢复**（原路放回）、**彻底删除**或**清空回收站**。回收站里的文件同样占用仓库空间，确认不再需要后记得彻底删除。

## 架构

```
浏览器（GitHub Pages 页面）
        │  POST /upload  /delete  /trash    GET /list  /download  /zip  /trash
        ▼
Cloudflare Pages 后端  https://file-cloud-share.pages.dev
        │  携带 GitHub 令牌
        ▼
GitHub 仓库 polytrack114514/storage
```

- 前端：本仓库 `index.html`，由 GitHub Pages 托管
- 后端：Cloudflare Pages 上的 `_worker.js`，持有 GitHub 令牌，对外提供上传/删除/列表/下载接口
- 前端通过仓库里的 `backend.json` 得知后端地址，当前为：

```json
{ "workerUrl": "https://file-cloud-share.pages.dev", "password": "" }
```

后端已部署完成，日常使用无需再做任何配置。若日后需要重新部署，把 `worker.js` 作为 `_worker.js` 上传到 Cloudflare Pages 项目，并配置环境变量即可。当前值：

| 变量 | 值 |
| --- | --- |
| `GH_TOKEN` | 加密变量，GitHub 令牌（不对外暴露） |
| `REPO_OWNER` | `polytrack114514` |
| `REPO_NAME` | `storage` |
| `BRANCH` | `main` |
| `ALLOW_ORIGIN` | `*` |
| `UPLOAD_PASSWORD` | 加密变量，上传/删除口令（已设置） |

## 保护机制

`backend.json`、`index.html`、`README.md`、`worker.js` 这四个基础文件受**后端强制保护**：

- 任何覆盖或删除请求，后端一律返回 `403`，即使绕过网页直接调用接口也无效
- 上传同名文件会被后端拒绝并提示，不会破坏站点
- 页面上额外标记为「不可删除」并隐藏删除按钮，上传时自动跳过

这三层中，前两端（后端拒绝）才是真正的保护，前端标记只是让人看得见。

## 说明

- 本仓库是**公开仓库**，上传的文件任何人都能看到，请勿存放敏感内容
- 单文件最大 100 MB，前端与后端双重校验，后端超限直接返回 `413`
- 同名文件不可覆盖，覆盖请求一律返回 `409`
- `.meta.json` 由后端自动维护，记录每个文件的上传时间，用于排序；界面不显示此文件，请勿手动修改
- `.trash/` 是回收站目录，删除的文件暂存在这里，界面同样不显示；它不参与统计，但会占用仓库空间
- 子目录中的同名文件不受保护（只有仓库根目录的四个基础文件受保护）
- 如果不想让陌生人随意上传，可在后端设置 `UPLOAD_PASSWORD`，并把同样的口令填进网页的口令框。注意口令只存在于 Cloudflare 环境变量里，不写在仓库中；但由于整个仓库公开，文件本身没有任何加密
- 后端接口：`GET /search?q=关键词`（跨目录搜索）、`GET /list`、`GET /stats`、`GET /download`、`GET /zip?path=目录`（可加 `&names=a,b,c` 只打包指定文件）、`GET /trash`、`POST /upload`、`POST /mkdir`、`POST /move`、`POST /delete`、`POST /trash`（`action=restore|purge|empty`）；所有 POST 接口都校验口令
- 适合文档、图片、代码等小文件，不适合当网盘存放大量大文件
