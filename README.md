# file-cloud-storage

云端文件中转站 —— 在任意电脑或手机上打开网页，拖拽上传，随时下载。

## 在线地址

**https://polytrack114514.github.io/file-cloud-storage/**

## 怎么用

1. 打开上面的网址
2. 把文件拖进「上传文件」区域（也可点「选择文件」或「选择整个文件夹」）
3. 文件会直接提交到本仓库，并自动出现在「云端文件」列表里
4. 换任何设备打开同一网址，都能看到并下载这些文件

支持多文件、整个文件夹上传，可指定目标子目录，带进度条和逐文件状态提示。

## 首次使用

第一次使用需要配置一次 GitHub 访问令牌（只需一次，之后浏览器自动记住，不会再看到令牌输入框）：

1. 点页面上的「如何获取令牌？」按钮
2. 在 GitHub 勾选 `repo` 权限，生成并复制令牌
3. 粘贴到页面，点「保存并连接」

令牌只保存在**你自己的浏览器**里，只会发送给 `api.github.com`，不会上传到任何第三方服务器。

## 说明

- 本仓库是**公开仓库**，上传的文件任何人都能看到，请勿存放敏感内容
- 单文件最大 100 MB
- 适合文档、图片、代码等小文件，不适合当网盘存放大量大文件
- 每台新设备首次使用时需要各配置一次令牌
